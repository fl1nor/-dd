# MEOW — пиксельная таверна гильдии

Первая рабочая версия: браузерная пиксельная таверна с общим онлайном, котиками-персонажами, перемещением и облачками чата.

## Запуск

1. Установи Node.js (LTS): https://nodejs.org/
2. Распакуй архив и открой терминал в папке `meow_guild`.
3. Выполни:

```bash
npm install
npm start
```

4. Открой http://localhost:3000
5. Чтобы проверить мультиплеер, открой адрес в двух окнах/браузерах.

## Управление

- WASD или стрелки — движение.
- Поле снизу — чат.
- E — действие с тем, что рядом (подсказка появляется над котом): читать доску объявлений, попросить молока у стойки, осмотреть полки и сундуки, погладить другого кота.
- 1–4 (или кнопки под картой) — эмодзи-реакции над головой: сердечко, довольный кот, сон, восклицание.
- Никнейм вводится при входе.

## Состав

- `server.js` — сервер Express + Socket.IO.
- `public/index.html` — интерфейс.
- `public/styles.css` — оформление.
- `public/app.js` — отрисовка таверны из спрайтов, анимация котиков, управление и чат.
- `public/shared/world.js` — общий для сервера и браузера файл: координаты спрайтов в листах, расстановка мебели, зоны столкновений.
- `public/assets/` — спрайты CraftPix и котики (условия использования — в `public/assets/CREDITS.md`).

## Важно

Это стартовый прототип. Сейчас никнеймы не защищены аккаунтами, сообщения не сохраняются, а у котиков пока только анимация ходьбы (в бесплатном наборе нет кадров покоя, сна и т. д.). Для публичного запуска понадобятся постоянные аккаунты, модерация чата, защита от спама и хранение данных.


## Как менять комнату

Вся расстановка — в `public/shared/world.js`: список `PROPS` (мебель, сортируется по Y вместе с котиками), `STATIC_LAYER` (коврик, баннер, окна) и `SPRITES` (где предмет лежит в листе и какая у него зона столкновений). Сервер и браузер читают один и тот же файл, поэтому коты не проходят сквозь мебель ни там, ни там.
